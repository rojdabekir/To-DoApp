# ✅ To-Do App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript.

The application allows users to add, complete, and remove tasks through a clean and straightforward interface.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Remove tasks
* Visual indication for completed tasks
* Simple and responsive user interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📸 Overview

The To-Do App provides a simple way to keep track of tasks and manage a personal to-do list directly in the browser.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd ToDoApp
```

### 3. Open the application

Open `index.html` in your browser.

## 📁 Project Structure

```text
ToDoApp/
├── index.html
└── src/
    ├── style.css
    └── script.js
```

## 📌 How It Works

1. Enter a task in the input field.
2. Add the task to the list.
3. Click on a task to mark it as completed.
4. Remove a task when it is no longer needed.

## 🎯 Project Goal

This project was created as a practice project to improve JavaScript fundamentals and gain experience with DOM manipulation and event handling.
